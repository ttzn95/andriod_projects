# Android Projects

A modern Android application built with Jetpack Compose, Kotlin Coroutines, and Material 3 design system. It functions as a project manager, architecture showcase, interactive component laboratory, and Kotlin code recipes repository.

## Features

- **Project Catalog & Dashboard**: Explore curated Android projects spanning E-Commerce, Health & Fitness, IoT Automation, AI Assistant, FinTech/Crypto, and Weather.
- **Interactive Component Playground**: Real-time interactive simulators for custom Canvas gauges, Material 3 buttons, touch drag gestures, and dynamic color theme swatches.
- **Live Project Simulators**: In-app interactive component sandboxes demonstrating real-time ECG waveform plotting, rotary thermostat dials, streaming AI chat bubbles, and crypto charts.
- **Curated Kotlin & Compose Snippets**: Production-grade architectural patterns for StateFlow, Canvas drawing, Type-safe navigation, and Room database flows.
- **Custom Project Creation**: Manage personal project milestones, tech stack tags, and implementation progress.

## Tech Stack & Architecture

- **Language**: Kotlin 2.0+
- **UI Framework**: Jetpack Compose with Material Design 3 (M3)
- **Architecture**: MVVM with Unidirectional Data Flow (`ViewModel` + `StateFlow`)
- **Graphics**: Compose `Canvas` 2D hardware-accelerated drawing
- **Build System**: Gradle Kotlin DSL (`build.gradle.kts`) with Version Catalog (`libs.versions.toml`)
